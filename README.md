# AX 경영 시뮬레이션 (Axmgmtsim)

AI 전환(AX) 기업의 경영자가 7년(28분기) 동안 **시장 진출 · 제품 선택 · 인재 영입 ·
조직 편성 · 투자 · M&A** 를 결정하고, 그 선택이 수주와 매출로 되돌아오는 것을 겪는
경영 시뮬레이션이다.

게임이자 동시에 **의사결정 도구**다. 엔진이 결정론적(시드 고정 순수 함수)이므로
같은 시점에서 다른 선택을 했다면 어땠을지를 **분포로** 비교할 수 있다.

```
▸ 반사실 분석 — 2022Q4 시점 · 이후 16분기 · 변형당 150판

■ 자체 성장 (이번 분기에 특별한 수 없음)
  누적 매출     중앙   693.4억   P10   567.2억   P90   802.1억
  목표 달성     100.0%   중앙 9분기 (P10 9 / P90 14)

■ 인수: 데이터 구축·라벨링 전문 B사 (45억, 전액 차입)
  누적 매출     중앙   843.9억   P10   709.7억   P90   945.4억
  목표 달성     100.0%   중앙 9분기 (P10 9 / P90 9)

■ 자체 증원: 같은 규모 24명 채용 (실적·자격 없음)
  누적 매출     중앙   853.5억   P10   707.1억   P90   953.2억
  목표 달성     100.0%   중앙 9분기 (P10 9 / P90 9)
```

## 지금 무엇이 되어 있나 (1차)

- ✅ **시뮬레이션 엔진** — 순수 TypeScript, 결정론적, I/O 없음
- ✅ **시드 데이터** — 사업 124건(2,589억) / 인재 20장 / M&A 대상 8곳 / 제품 6개 / 회사 프로필 2개
- ✅ **CLI** — 28분기 플레이, 전략 배치 시뮬레이션, 반사실 분석, 데이터 검증
- ✅ **반사실 분석** — 같은 상태에서 선택을 갈라 몬테카를로로 비교
- ✅ **테스트 27개** — 결정론·게이트·플라이휠·재무·M&A·리플레이
- 🔜 **웹 대시보드 / 모바일 앱** — 2·3차. 연동 구조(이벤트 소싱)는 확정되어 있다

## 빠른 시작

```bash
npm install
npm run validate                                   # 시드 데이터 검증
npm test                                           # 엔진 테스트
npm run sim -- list                                # 프로필·전략 목록

# 사람이 직접 28분기 플레이
npm run sim -- play --profile ontact --seed 42

# 봇이 플레이하는 걸 관전 (TTY 불필요)
npm run sim -- play --profile ontact --seed 42 --strategy public-focus

# 전략 5종 배치 시뮬레이션 + 밸런싱 자동 판정
npm run sim -- auto --strategy all --runs 200

# 반사실 분석: 12분기 시점에서 '인수 vs 자체성장 vs 자체증원'
npm run sim -- compare --at 12 --runs 150 --horizon 14
```

### 플레이 중 명령어

```
b <번호> [할인율%] [c]     입찰 (c 를 붙이면 컨소시엄)     예: b 1 10 c
h <번호>                   인재 영입
m <번호> [cash|debt|mixed] 인수
i sales|marketing|training <금액억> [세그먼트|도메인]
i cert <자격>              자격 취득 착수                   예: i cert isms
r <번호> <금액억>          제품 R&D
+ / - <등급> <인원>        채용 / 감원
auto                       이번 분기는 봇에게 맡김
go 또는 엔터               다음 분기로
```

## 모델이 가르치려는 것

| | 어디서 구현되나 |
|---|---|
| **공공 플라이휠** — 수주 → 실적 → 자격 → 더 큰 수주 | `delivery.ts` |
| **영입은 즉효약이 아니다** — 효과 발현에 2~3분기, 사기 낮으면 그 전에 이탈 | `talent.ts` |
| **인수는 시간을 사는 것** — 자격·실적 승계로 몇 년 단축, 대신 통합 실패와 원리금 부담 | `mna.ts` |
| **가격 인하는 대개 손해** — 공공 협상계약은 가격 배점이 10점뿐 | `bidding.ts` |
| **과다 수주는 조직을 망가뜨린다** — 품질 하락 → 관계자본 하락 → 다음 사업 불리 | `delivery.ts` |

## 밸런싱 현황

`npm run sim -- auto` 가 5개 기준을 자동 판정한다. 2026-08 기준 `ontact` 프로필:

| 전략 | 누적매출(중앙) | 최종현금 | 파산율 | 목표달성 |
|---|---:|---:|---:|---:|
| 공공 집중 | 680억 | 111억 | 0% | 78% |
| M&A 우선 | 845억 | 73억 | 4% | 77% |
| 제품 R&D | 340억 | 18억 | 3% | 19% |
| 균형 | 301억 | 15억 | 4% | 13% |
| 대기업 집중 | 299억 | 8억 | 16% | 57% |

**4/5 통과.** 미충족 1건은 최고-최저 전략 격차 2.75배(목표 2.5배 미만)로,
원인은 `균형`·`대기업 집중` 봇이 여러 세그먼트에 자원을 분산해 어디서도 임계 규모에
못 미치는 것이다. 모델 결함이라기보다 봇 전략의 한계이며, 사람이 플레이하면
상황에 맞춰 집중할 수 있어 격차는 더 줄어든다.

## 데이터에 대한 고지

시드 데이터의 사업명·발주기관·예산은 **2020~2026년 국내 공공 AI·교육 사업의
실제 유형을 참고해 손으로 작성한 큐레이션 데이터**이며, 특정 공고의 실제 기록이
아니다. 기업 고객은 실명 대신 `국내 대형 제조사 A` 같은 익명 표기를 쓴다.

실제 입찰 판단에 쓰려면 나라장터/조달청 API 연동(4차)이 필요하며,
스키마는 그 전환을 염두에 두고 설계했다. → [`docs/02-data-schema.md`](docs/02-data-schema.md)
